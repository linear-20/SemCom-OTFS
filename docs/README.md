# 文档目录

这个目录里保留三份主文档和一个历史归档目录。

## 1. 项目文件使用说明书

文件：

```text
PROJECT_MANUAL.md
```

用途：

```text
说明项目里每个文件是什么、每个脚本怎么用、常见参数怎么改、图片怎么传入链路。
```

优先阅读场景：

```text
想跑实验
想换图片
想改 DD grid、CP、SNR、信道参数
想知道某个 .py 文件负责什么
```

## 2. 后续规划书

文件：

```text
ROADMAP_NEXT.md
```

用途：

```text
说明后续每一阶段要做什么，包括 Perceiver 短训练、正式训练、评估脚本、真实 token 数据集、channel-aware receiver、learnable mapper 和图片级评估。
```

优先阅读场景：

```text
想知道下一步做什么
想安排实验顺序
想避免直接跳到端到端导致系统复杂度失控
```

## 3. 对话压缩摘要

文件：

```text
CONVERSATION_SUMMARY.md
```

用途：

```text
用于开启新对话时快速恢复上下文，减少模型忘记项目状态或产生幻觉的概率。
```

优先阅读场景：

```text
开启新对话
让另一个模型接手
快速回顾当前项目状态和已完成阶段
```

## 4. 历史归档

目录：

```text
archive\
```

用途：

```text
保存旧任务说明和早期设计文档。一般不需要修改，只在需要追溯阶段性设计时查看。
```
